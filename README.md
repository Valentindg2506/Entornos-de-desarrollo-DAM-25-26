# Entornos de Desarrollo · DAM 25/26

Apuntes y prácticas de la asignatura **Entornos de Desarrollo** de 1.º de Desarrollo de Aplicaciones Multiplataforma (DAM), curso 2025/2026.

## De qué trata la asignatura

Entornos de Desarrollo trata todo lo que rodea al código: el ciclo de vida del software, los IDE y herramientas que usa un programador, el control de versiones, la documentación, la refactorización y, sobre todo, las **pruebas** para comprobar que un programa hace lo que debe.

## Qué hay en el repositorio

| Carpeta / archivo | Contenido |
|---|---|
| `Apuntes/U1` | Primera unidad: desarrollo de software y entornos de trabajo. |
| `Apuntes/001-Pruebas de caja blanca` | Diseño de pruebas a partir de la estructura interna del código: caminos, condiciones y cobertura. |
| `Apuntes/001-Portafolio.py` | Script de Python usado como práctica de la asignatura. |

## Para qué sirve

Es el material con el que estudié la asignatura y donde practiqué las técnicas de prueba sobre código propio.
